HEALTHCARE APP REDESIGN

Revamping the appointment booking experience with improved accessibility and streamlined user flows.

Project

Healthcare Appointment System

What I Did

  • UX Research
  • UI Design
  • Accessibility Audit
  • User Testing

Tools

Figma, Miro, UserTesting, Axe DevTools

Timeline

3 months (Q1 2026)

The Challenge

The existing appointment booking system suffered from a 40% drop-off rate. Users reported confusion with the multi-step process, difficulty finding suitable time slots, and significant accessibility barriers that prevented completion of bookings.

The Solution

I led a complete redesign of the booking experience, reducing steps from 7 to 4, implementing smart time suggestions, and ensuring WCAG 2.1 AA compliance. The new system prioritizes clarity and accessibility while maintaining all necessary functionality.

The Work

Initial Research

Through analytics analysis and user interviews with 15 patients, I identified key pain points in the booking flow. Drop-off data showed users abandoning at the time selection step, while accessibility testing revealed critical issues with screen reader navigation.

Stakeholder Insights

Key stakeholders identified three critical issues that needed addressing:

  • Inconsistent Design: UI patterns varied across different booking steps, causing confusion
  • Outdated Copy: Instructions were unclear and used medical jargon
  • Lack of Accessibility: System failed basic WCAG requirements

Design Principles

Progressive Disclosure

Show only what users need at each step to reduce cognitive load and decision fatigue.

Clear Communication

Use plain language and visual cues to guide users through the booking process.

Inclusive Design

Ensure every interaction is accessible to users of all abilities and assistive technologies.
